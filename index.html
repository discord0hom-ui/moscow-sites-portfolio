Сайты для бизнеса Москвы

17

сайтов для реальных московских компаний

Пекарня у Курской, кофейня с капибарами, барбершоп, стоматология, ветклиника, тату-студия, книжный, ресторан и ещё девять. Данные — из их открытых карточек в 2ГИС, у каждого сайта своя композиция под нишу, рабочая форма заявки и версия для телефона.

Настоящие данные

Адрес, часы, телефоны и рейтинг взяты из карточек 2ГИС. Отзывы и цифры не выдуманы.

Своя композиция

Расписание для йоги, табло «открыто сейчас» для ветклиники, полка книг для книжного — первый экран выводится из главного действия клиента.

Заявки работают

Формы собирают заявку и отправляют её в WhatsApp, звонком или письмом — без сервера и без потерь.

Быстро и на телефоне

Один HTML-файл на сайт, лёгкие фото WebP, видимый фокус и учёт «уменьшить движение».

Все сайты — концепты для портфолио, не официальные сайты компаний. Фото на них иллюстративные, из открытых библиотек с лицензиями CC; авторы указаны на каждом сайте.
