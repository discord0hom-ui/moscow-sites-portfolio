# Портфолио — 17 готовых сайтов

Главная страница: `index.html`. Сайты: `sites/<папка>/index.html`. Общие скрипт и стили: `sites/_общее/`.

Все сайты — концепты с онлайн-записью, анимацией и адаптацией под телефон. Названия, адреса, цены и фото условные. Номер WhatsApp — заглушка. Перед показом клиенту замените данные и фото.

Старые московские концепты перенесены в `_архив/portfolio-старый/` вместе со служебными файлами (`_stage`, `_shots`, старый `index.html`).
