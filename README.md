## Как устроено

- `index.html` — главная портфолио, список работ берётся из `sites.json`.
- `sites/<slug>/index.html` — сайт, `img/` — фото WebP и `credits.json` с авторами и лицензиями.
- `assets/kit.js` — общий скрипт: мобильное меню, «открыто сейчас» по московскому времени, формы заявки.
- `tools/photos.py` — поиск фото с открытыми лицензиями (Openverse) и сохранение в WebP.
- `tools/shots.py` — скриншоты всех сайтов (телефон и компьютер) и превью для главной.

## Свой домен

1. В настройках репозитория: Settings → Pages → Custom domain — впишите домен.
2. У регистратора домена добавьте запись CNAME `www` → `<логин>.github.io` (или четыре A-записи GitHub Pages для корня домена).
3. Контакты на главной: в `index.html` заполните `CONTACTS` (Telegram, WhatsApp, телефон, почта).

## Важно

Все сайты — концепты для портфолио, а не официальные сайты компаний: это написано в подвале каждого, страницы закрыты от индексации (`noindex`). Фото иллюстративные, из открытых библиотек (CC0, CC BY, CC BY-SA), авторы указаны на сайтах. Если компания согласится на сайт, замените фото на её собственные и уберите пометку «концепт».
