# Портфолио: сайты, боты, автоматизация

Личный сайт-портфолио разработчика плюс библиотека демонстрационных сайтов.

- `index.html` — портфолио: услуги, работы, процесс, цены, вопросы, контакты.
- `demo/index.html` — 17 демо-сайтов для разных ниш.
- `sites/<ниша>/index.html` — сами демо-сайты.

## Важно про содержание

Всё, что помечено на сайте как «демо», «концепт» или «шаблон», — это действительно демонстрационные
материалы, а не внедрённые коммерческие проекты. Названия компаний, адреса, телефоны, цены и фото
в демо условные. Номер WhatsApp в демо-сайтах — заглушка.

Отзывов, логотипов клиентов и цифр выручки на сайте нет намеренно: их нельзя подтвердить.

## Запуск и публикация

Инструкция — в [README-DEPLOY.md](./README-DEPLOY.md). Коротко: открыть `index.html` или поднять
`python -m http.server`, заполнить `site.config.js` (имя и каналы связи), затем опубликовать
корень репозитория на GitHub Pages или любом статическом хостинге.

## Стек

Чистые HTML, CSS и JavaScript. Без сборки, зависимостей и внешних шрифтов: страница работает
офлайн и открывается двойным щелчком.
